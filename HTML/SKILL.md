# HTML

- Use the elements most appropriate semantically.
- Use as little HTML as possible.
- Always identify elements with a class and a specific "human" ID that allow
  external scripts to scrape or modify the content.
- Use HTML5 tags like `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`,
  and `<footer>`.
- Use Accessible Rich Internet Applications (ARIA).
- Validate all HTML output against an HTML validator (preferably the W3C one),
  and fix any errors.
