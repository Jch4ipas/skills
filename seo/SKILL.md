- Always add the meta tag `title`, `description`, `charset`, `author`, 
  `copyright`, `robots` with page and site relevant information.
- Use the `alt` and the `title` attributes for images.
- Use the `rel=` attributes for links.
- Add all OpenGraph meta tags (https://ogp.me/).
- When adding an address, use the `<address>` tag.
- Add microformats whenever relavant (https://microformats.org).
