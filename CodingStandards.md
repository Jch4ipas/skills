# Coding standards

- Respect coding standards of each of programming langage you use.
- Prefer double spaces `  ` than quadriple `    `.
- Do not use tabs apart from Makefile or whenever it's obligatory.
- Keep things simple.
- OnceAndOnlyOnce: no duplication (https://wiki.c2.com/?OnceAndOnlyOnce).
- Document with links to official language reference or stack overflow.
